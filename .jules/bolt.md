## 2024-06-11 - Fast 2D Grid Coordinate Tracking in React
**Learning:** Tracking 2D grid coordinates with strings (e.g., \`\${x},\${y}\`) as keys in \`Map\` or \`Set\` structures inside of \`useMemo\` or frequent render cycles creates significant performance overhead due to constant string allocation and garbage collection.
**Action:** Replace string-based 2D lookups with 1D typed arrays (\`Int8Array\` or \`Int32Array\`) using the formula \`index = y * width + x\`. This avoids memory allocation during the render cycle and is roughly 3x-6x faster for lookups and iterations.
## 2024-05-24 - React Game Loop State Optimization
**Learning:** Using React state (like `useState`) for values frequently updated within or driving a `setInterval` loop (such as input buffers/queued direction or target coordinates) forces the `useEffect` dependencies to include that state. This triggers interval cleanup and reset mid-tick whenever the state changes (e.g. keypresses or eating food), causing noticeable UI stutter and input lag in tight loops.
**Action:** When building games or interval-driven animations in React, utilize `useRef` for frequently mutated game state parameters that don't need independent synchronous re-renders, thereby avoiding interval resets while safely referencing the current values inside the loop closures.
